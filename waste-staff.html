รายชื่อผู้ใช้งานและสิทธิ์การเข้าถึงเมนู (Role-Based Access Control)
คลิกปุ่ม "กำหนดสิทธิ์ / แก้ไข" เพื่อตั้งค่า User, รหัสผ่าน และติ๊กเลือกสิทธิ์แต่ละเมนู
ชื่อเจ้าหน้าที่ / ตำแหน่ง Username (รหัสผู้ใช้) เบอร์ติดต่อ / อีเมล ระดับสิทธิ์ (Role) สิทธิ์การเข้าถึงเมนูในระบบขยะ สถานะ จัดการ

2. กำหนดระดับสิทธิ์และการเข้าถึงแต่ละเมนู
แก้ไขได้ 13 เมนู
ล็อกการแก้ไขสิทธิ์เมนู: คุณสามารถแก้ไขข้อมูลส่วนตัวและ User / Password ของตัวเองได้ แต่ไม่สามารถแก้ไขระดับสิทธิ์หรือสิทธิ์ในการเข้าถึงเมนูต่างๆ ของตัวเองได้ (เฉพาะ Admin เท่านั้น)
ตารางกำหนดสิทธิ์รายเมนู (ติ๊กถูกเพื่อกำหนดสิทธิ์)
เมนูในระบบค่าธรรมเนียมขยะ ดูได้อย่างเดียว แก้ไขเมนูนี้ได้ สิทธิ์ที่ได้
คำแนะนำ: ติ๊กช่อง "ดูได้อย่างเดียว" เพื่อให้เปิดดูข้อมูลได้แต่กดเพิ่ม/ลบ/แก้ไขไม่ได้ • ติ๊กช่อง "แก้ไขเมนูนี้ได้" เพื่อให้ทั้งดูและแก้ไขข้อมูลได้ • หากไม่ติ๊กเลยทั้ง 2 ช่อง เมนูนั้นจะถูกซ่อนจากผู้ใช้งานรายนี้
